# HR Data Analytics Dashboard – Power BI

## 📌 Project Overview
Designed an interactive HR analytics dashboard using **Power BI** and **Excel** to analyze employee presence data.

The dashboard provides insights into:
- Attendance percentage
- Work From Home (WFH %) trends
- Sick Leave (SL %) analysis
- Day-wise and time-based attendance patterns
- Employee-level attendance tracking

This solution helps HR teams reduce manual reporting effort and saves **3–4 hours of work daily**.

---

## 🛠 Tools Used
- Power BI
- Microsoft Excel
- Data Cleaning & Transformation
- Data Visualization

---

## 📊 Key Metrics
- Attendance %
- WFH %
- Sick Leave %
- Day-of-week trends
- Monthly presence insights
